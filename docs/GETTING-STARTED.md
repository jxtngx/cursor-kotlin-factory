# Getting started

1. Open this repo in Cursor.
2. Run `@init-app`.
3. Answer product (TAK plugin vs Compose app) then device class.
4. Approve the technical-requirements plan.
5. Let `@chief-architect` → SME → `@scrum-master` staff tickets.

Do not create an Android Studio project until the spec is approved.

ATAK-CIV plugin work needs the official SDK from [tak.gov](https://tak.gov) / [ATAK-CIV](https://github.com/deptofdefense/AndroidTacticalAssaultKit-CIV).
Install the matching **SDK** host APK, not a random Play Store build, when developing a plugin.
